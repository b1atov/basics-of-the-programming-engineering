## Запуск

Нужен Python 3. Из корня репозитория:

```
python3 Lab_2/A4.py
```

Программа запросит входные данные с клавиатуры (каждое число с новой строки).
`A1_A3.py` ввода не требует; число в A3 вычисляется несколько секунд.
